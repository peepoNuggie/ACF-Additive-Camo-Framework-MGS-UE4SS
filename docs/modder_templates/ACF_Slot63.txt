; --- How well it hides you, everywhere ----------------------------------------
;
; BaseCamo applies whatever you are standing against. Positive hides you,
; negative exposes you. 0 behaves like being Naked.
;
; For scale, these are the game's own values:
;       Naked            0
;       Olive Drab      10
;       Tiger Stripe    30
;       Naked Woodland  45
;       Gold          -100
;
; Stored as a signed byte, so -128 to 127. Stay within -100 to 100.

BaseCamo=0


; --- Per-terrain values (optional) --------------------------------------------
;
; This is what makes a camo feel like a real one. A vanilla camo is not one
; number - it has a value for every surface AND every stance. That is why Water
; works underwater, Snow works against white, and going prone in grass helps.
;
; Each line takes FIVE numbers, in this order:
;
;       stand , crouch , prone , wall-stand , wall-crouch
;
; They ADD to BaseCamo. BaseCamo=10 with CamoGrass=20,30,50,35,40 gives +30 when
; standing in grass and +60 prone in grass. A surface left at 0 just gets
; BaseCamo in every stance.
;
; You may also write a single number - CamoGrass=35 - and ACF uses it for all
; five. That is simpler, but going prone will then gain you nothing on that
; surface, which is not how vanilla camos behave.
;
; This is the REAL Tiger Stripe row, so you can see the shape of a jungle camo
; and how much stance is normally worth:
;
;       CamoGrass      = 35, 50, 80, 55, 60      prone is worth +45 over standing
;       CamoWoodGreen  = 30, 60, 80, 70, 75
;       CamoSoilBrown  = 30, 60, 75, 65, 70
;       CamoLeaf       =  0, 30, 50, 40, 45
;       CamoWhite      = -10, 20, 40, 30, 35     poor, but prone still saves you
;       CamoRoomBlack  = -10,  5, 20, 10, 15     worst case
;
; Note it is not all positives. A good camo is BAD somewhere - that is what makes
; picking one interesting, and it is worth deciding where yours should struggle.
;
; Surfaces are chosen by COLOUR and MATERIAL, not by area. Standing by a tree you
; may be on SoilBrown, then ObjBrown pressed against the trunk, then Grass a step
; later.

;                 stand crouch prone  wall  wallcr
